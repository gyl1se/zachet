# Шпаргалка по вариантам (все 36)

Текущий код реализует **Вариант 1**.

Чтобы переключить вариант, нужно изменить **два места**:

1. **Правило конкурса** → в классе `ScholarshipManager`
   - `admissionPredicate` (условие допуска студента)
   - метод `ratingOf(...)` (как считается рейтинг)

2. **Аналитика** → метод `runAnalytics()` в классе `Main`

Ниже для каждого варианта написано точно, что менять.

---

## Общие правила (одинаковы для всех вариантов)

- Участник = студент.
- Побеждают не более `limit` студентов с наибольшим рейтингом.
- При равенстве рейтинга преимущество имеет **меньший studentId**.
- У победителя `awarded = true` ставится **только одной** заявке — с наибольшим баллом (при равенстве — с меньшим id).
- Повторный конкурс полностью заменяет предыдущий результат.
- Аналитика всегда идёт через **Stream API** и не зависит от результата конкурса.

- Рейтинг: максимальный балл заявок студента

Вывести ID трёх студентов с наибольшим личным максимумом среди тех, у кого есть заявка ≥ 60. При равенстве — меньший studentId.

private static void runAnalytics() {
    System.out.println("Аналитика 1:");

    Map<Integer, Double> maxScores = manager.getAnalyticsStream()
            .collect(Collectors.groupingBy(
                    ScholarshipApplication::getStudentId,
                    Collectors.mapping(
                            Scorable::calculateScore,
                            Collectors.maxBy(Double::compare)
                    )
            ))
            .entrySet().stream()
            .filter(e -> e.getValue().isPresent() && e.getValue().get() >= 60.0)
            .collect(Collectors.toMap(
                    Map.Entry::getKey,
                    e -> e.getValue().get()
            ));

    List<Integer> top3 = maxScores.entrySet().stream()
            .sorted((e1, e2) -> {
                int cmp = Double.compare(e2.getValue(), e1.getValue()); // DESC
                if (cmp != 0) return cmp;
                return Integer.compare(e1.getKey(), e2.getKey());       // ASC
            })
            .limit(3)
            .map(Map.Entry::getKey)
            .collect(Collectors.toList());

    if (top3.isEmpty()) {
        System.out.println("Нет подходящих студентов.");
    } else {
        System.out.println("ID трёх студентов: " + top3);
    }
}

private static void runAnalytics() {
    System.out.println("Аналитика 2:");

    Map<Integer, List<ScholarshipApplication>> byStudent = manager.getAnalyticsStream()
            .collect(Collectors.groupingBy(ScholarshipApplication::getStudentId));

    List<Integer> result = byStudent.entrySet().stream()
            .filter(e -> {
                boolean hasAcad = e.getValue().stream().anyMatch(a -> a instanceof AcademicApplication);
                boolean hasRes  = e.getValue().stream().anyMatch(a -> a instanceof ResearchApplication);
                if (!hasAcad || !hasRes) return false;

                double maxAcad = e.getValue().stream()
                        .filter(a -> a instanceof AcademicApplication)
                        .mapToDouble(Scorable::calculateScore)
                        .max().orElse(0);
                double maxRes = e.getValue().stream()
                        .filter(a -> a instanceof ResearchApplication)
                        .mapToDouble(Scorable::calculateScore)
                        .max().orElse(0);

                return Math.abs(maxAcad - maxRes) <= 10;
            })
            .map(Map.Entry::getKey)
            .sorted()
            .collect(Collectors.toList());

    if (result.isEmpty()) {
        System.out.println("Нет подходящих студентов.");
    } else {
        System.out.println("ID студентов: " + result);
    }
}

private static void runAnalytics() {
    System.out.println("Аналитика 5:");

    // средние баллы по типам
    double avgAcademic = manager.getAnalyticsStream()
            .filter(a -> a instanceof AcademicApplication)
            .mapToDouble(Scorable::calculateScore)
            .average()
            .orElse(0);

    double avgResearch = manager.getAnalyticsStream()
            .filter(a -> a instanceof ResearchApplication)
            .mapToDouble(Scorable::calculateScore)
            .average()
            .orElse(0);

    Optional<ScholarshipApplication> result = manager.getAnalyticsStream()
            .min(Comparator
                    .comparingDouble((ScholarshipApplication a) -> {
                        double avg = (a instanceof AcademicApplication) ? avgAcademic : avgResearch;
                        return Math.abs(a.calculateScore() - avg);
                    })
                    .thenComparingInt(ScholarshipApplication::getId)
            );

    if (result.isEmpty()) {
        System.out.println("Нет заявок.");
    } else {
        System.out.println("Найденная заявка: " + result.get().getDetails());
    }
}

private static void runAnalytics() {
    System.out.println("Аналитика 6:");

    Map<String, Long> result = new LinkedHashMap<>();
    result.put("AcademicApplication", 0L);
    result.put("ResearchApplication", 0L);

    Map<String, Long> counted = manager.getAnalyticsStream()
            .filter(a -> a.calculateScore() >= 60)
            .collect(Collectors.groupingBy(
                    a -> a.getClass().getSimpleName(),
                    Collectors.mapping(
                            ScholarshipApplication::getStudentId,
                            Collectors.collectingAndThen(Collectors.toSet(), set -> (long) set.size())
                    )
            ));

    result.putAll(counted);

    result.forEach((name, count) ->
            System.out.printf("%s → %d студентов%n", name, count));
}

Аналитика 1:
  ID трёх студентов с наибольшим личным максимумом

  По возрастанию ID студентов, имеющих оба типа заявок,
  если лучшие баллы по двум типам отличаются не более чем на 10

Аналитика 3:
  Map<Integer, Double>: studentId → средний балл
  только студенты с ≥2 заявками

Аналитика 4:
  По возрастанию ID студентов, подавших ≥2 заявки
  и не имеющих ни одной заявки <60

Аналитика 5:
  Заявка с наименьшим |балл − средний_балл_её_типа|
  (при равенстве — меньший id)
  Результат: Optional<ScholarshipApplication>

Аналитика 6:
  Map<String, Long>: имя класса → кол-во разных студентов
  с заявкой этого типа ≥60
  (оба типа, при отсутствии — 0)
